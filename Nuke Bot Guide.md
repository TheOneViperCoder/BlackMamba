##### You need to have the token of a bot that is in the server you intend to nuke, place the bot token in dependencies/Token.txt, then execute the desired commands in the target server.



###### &#x20; **\[Commands list]:**

###### 

* ###### **!nuke** = Deletes all channels, creates new, spam pings everyone, changes server name and icon.
* ###### **!changename** = Changes the server's name.
* ###### **!changeicon** = Changes the server's icon.
* ###### **!deletechannels** = Deletes all channels (not recommended if you intend to nuke the server afterwards and do not have admin perms, as you won't be able to execute other commands).
* ###### **!spamall** = Spams the nuke message without doing anything else.
